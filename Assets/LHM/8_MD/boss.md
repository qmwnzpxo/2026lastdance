## 5. 상태 (FSM)

| 상태 | 스프라이트 | 설명 |
|---|---|---|
| Appearing | lending | 등장 착지, 완전 무적 |
| Idle | Idle | 패턴 선택 후 즉시 Telegraph로 |
| 🆕 Telegraph | Idle + 눈 색 이펙트 | 패턴 예고 (9장 색 규칙) |
| Attacking | 패턴별 | 6장 |
| 🆕 Punishable | 패턴별 복귀 프레임 | **반격 틈** — 받는 피해 ×1.2 |
| Resting | Idle | 1페이즈 1.5초 / 2페이즈 0.8초, 플레이어 쪽으로 걷기 |
| 🆕 Stunned | lending 1~2프레임 정지 | 벽 충돌 기절 1.5초, 받는 피해 ×1.2 |
| 🆕 Groggy | lending 최저 프레임 정지 | 그로기 4초, 받는 피해 ×1.5, 낙섬 QTE 가능 |

| Dead | lending + 폭발 이펙트 | 10장 |

## 6. 패턴 상세

> 프레임 시간은 **예고는 길게, 공격은 짧게, 복귀는 다시 길게**가 원칙이다. 아래 시간은 시작값이며 현민이 SO에서 튜닝한다.

### P1. 부스터 점프 내려찍기 🆕

| 항목 | 내용 |
|---|---|
| 시험하는 액션 | **이동 / 점프** |
| 흐름 | jumping 1~2프레임 웅크림(0.5초, 예고) → 3~5프레임 도약(빠르게) + 부스터 불꽃 → 천장 + 5 Unit 높이로 화면 밖으로 사라짐 → **바닥에 그림자 표시**, 1.2초 동안 플레이어 x좌표 추적 → 0.4초 그림자 고정(마지막 회피 기회) → 낙하 → lending 1프레임 착지 |
| 화면 밖 처리 | 도약 후 화면 밖에 있는 동안 **몸체 콜라이더를 끄고 무적** (자물쇠 아이콘은 띄우지 않음). 낙하 시작 시 다시 켬 |
| 판정 | 착지 지점 몸체 범위 데미지 8 + **좌우로 퍼지는 충격파** (바닥 높이, 데미지 4, 속도 12) |
| 충격파 높이 | **플레이어 점프로 넘을 수 있는 높이** (시작값 1 Unit, SO) |
| 정답 | 그림자에서 벗어나기 → 충격파는 점프로 넘기 |
| 반격 틈 | lending 2~6프레임 일어나는 동안 1.2초 (Punishable) |
| 연출 | 착지 프레임 히트스톱 0.08초, 화면 흔들림 강, 흙먼지·파편 파티클 |

### P2. 질주 돌진 🔁

| 항목 | 내용 |
|---|---|
| 시험하는 액션 | **일섬 (무적 통과)** |
| 흐름 | Telegraph 눈 빨강 2회 깜빡 + 몸을 뒤로 젖힘(runboost 1프레임 정지 0.6초) → runboost 루프로 직선 돌진 + 잔상 → 벽에 닿거나 화면 끝까지 |
| 판정 | 몸체 범위 데미지 6, 넉백 강 |
| 정답 | 정면으로 **일섬해서 뚫고** 보스 뒤로 빠지기 (점프로는 못 넘는 높이) |
| 보상 | 플레이어를 못 맞히고 벽에 닿으면 **벽 충돌 → Stunned 1.5초** (lending 1~2프레임 정지 + 머리 위 스파크) + 그로기 +25 |
| 반격 틈 | 벽 충돌 시 Stunned 1.5초 / 플레이어를 맞혔으면 0.6초 |

### P3. 짓밟기 🔁 (v1 "하단 공격(밟기)" 대체)

| 항목 | 내용 |
|---|---|
| 시험하는 액션 | **거리 판단 / 일섬 회피** |
| 흐름 | 짓밟기 1~3프레임 다리 들기 → **4프레임(다리 든 자세) 0.45초 정지** (예고) → 5~6프레임 각 0.05초 (전방 내려찍기) → 7~9프레임 다리를 거두며 복귀 |
| 판정 | 5~6프레임만 활성, 전방 3 Unit, 데미지 5, 넉백 |
| 정답 | 예고 동안 거리를 벌리거나, 내려찍는 순간 일섬으로 보스 뒤로 |
| 반격 틈 | 7~9프레임 동안 0.9초 |
| 연출 | 내려찍는 프레임 히트스톱 0.05초, 발밑 흙먼지 |

### P4. 포드 곡사 일제 사격 🔁 (v1 "곡사포" 대체)

| 항목 | 내용 |
|---|---|
| 시험하는 액션 | **이동 / 일섬으로 포탄 베기** |
| 흐름 | Telegraph 눈 노랑 → 포드 시트 1→7 **위로 들림** → 포탄 6발 연속 발사(0.25초 간격) → 바닥에 착탄 경고 마커 1초 → 순서대로 낙하(0.4초 간격) |
| 판정 | 착탄 지점 반경 1.5, 데미지 6 |
| 탄종 | 일반 / 공중폭발 / 바운스 (v1 가중치 랜덤 유지) |
| 정답 | 경고 마커를 피해 이동. 떨어지는 포탄을 **일섬으로 베면 공중에서 폭발** (피해 없음) |
| 반격 틈 | 발사하는 동안(약 1.5초) 보스가 제자리 — 포탄을 피하며 때릴지 판단 |

### P5. 포드 직사 연사 🔁 (v1 "기관총 3연발·연사" 대체)

| 항목 | 내용 |
|---|---|
| 시험하는 액션 | **회피 → 반격** (⏳ 패링 구현 후: 패링) |
| 흐름 | Telegraph 눈 노랑 → 포드 시트 **앞으로 내려옴**(정지 0.4초) → 3발 연사(0.2초 간격, 플레이어 조준) |
| 판정 | 탄 1발 데미지 3, 속도 14 |
| 정답 | 조준선에서 벗어나거나 점프로 피한 뒤 **연사 직후 반격 틈에 공격** |
| ⏳ 패링 구현 후 | 타이밍 맞춰 기본 공격으로 **패링 → 탄이 보스에게 반사** (반사 탄 데미지 10, 그로기 +15) |

## 9. 예고(Telegraph) 규칙

**눈 색은 패턴 예고 전용이다.** 페이즈 표시는 스프라이트 틴트(8장), 콤보 시작은 별도 신호로 구분한다.
