## 2. 보스룸 (1-8 섹션) 공간 규격

- 단일 씬 안에 있지만 거대 레이저 연출 등을 감당하기 위해 **가장 큰 방**으로 설계한다.
- **맵 규격:** 가로 40 Unit × 세로 30 Unit 이상의 평탄한 구조
- 직전 구역(1-7)에 대형 상자 2개를 배치해 전투 진입 전 칩 교체(R키)와 체력 회복을 유도한다.

### 1페이즈 공간 연출
- 보스는 중앙 상단에 스폰되고 양옆 연결부에서 회전 레이저를 발사한다.
- 동시에 보스 내부에서 레드(Type A) / 블루(Type B) / 그린(Type C) 판넬이 스폰되어 방 안을 무작위로 이동하며 플레이어를 공격한다.

### 2페이즈 공간 연출
- 맵 하단 정중앙에 '거울' 오브젝트가 등장한다.
- 화면 양 끝에서 레이저 벽이 좁혀 온다.
- 보스 아래 나타난 오브젝트와 상호작용해 커맨드를 입력하는 **아재 패턴** 기믹을 수행할 공간이 중앙에 보장되어야 한다.

## 3. 아키텍처 — FSM + Behavior Tree 하이브리드

| 구성 요소 | 역할 |
|---|---|
| **FSM (`BossController`)** | 보스의 생애주기(등장 → 대기 → 공격 → 휴식 → … → 사망)와 페이즈 전환 관리 |
| **Behavior Tree (`BossBT` 네임스페이스)** | Attacking 상태 진입 시 플레이어와의 거리 조건에 따라 실행할 콤보 결정 |
| **`BossAttackPatterns` (MonoBehaviour)** | 공격 판정 / 이펙트 / 사운드 전담. `BossController`는 호출만 한다 |

| 스탯 | 설명 | 수치 |

## 5. 상태 (FSM State)

| 상태 | 설명 |
|---|---|
| **Appearing** | 등장 연출 중, 완전 무적 |
| **Idle** | BT 트리 선택·리셋 후 즉시 Attacking으로 전이 |
| **Attacking** | 선택된 BT 콤보를 매 프레임 tick하며 공격 |
| **Resting** | 콤보 종료 후 휴식(1페이즈 2초 / 2페이즈 1초), 플레이어 쪽으로 접근 이동 |
| **Walk** | 1페이즈 이동 시 걷기 애니메이션 |
| **BoosterJump** | 2페이즈 이동 시 자동 진입하는 부스터 비행 애니메이션 |
| **Hit** | 피격 연출용 상태값 (현재는 별도 코루틴 없이 무적/점멸 로직으로 처리) |
| **Dead** | 정리 → 애니메이션 → 2초 대기 → 비활성화 |

```
Appearing → Idle → Attacking → Resting → Idle → … 
                         │
            (HP < 50% 최초 1회) → 페이즈 전환 → Idle (2페이즈 루프)
                         │
                  (HP ≤ 0) → Dead
```

## 6. 페이즈 및 패턴 흐름

### 6-1. 등장 연출
1. 현재 위치 기준 **+20 Unit 상공**에서 2초간 낙하해 착지
2. 1초 대기 후 배틀 BGM 재생
3. Idle 상태 진입
- Appearing 동안은 완전 무적이며 플레이어 공격 판정이 전혀 들어가지 않는다.

### 6-2. 페이즈 진입 조건
- 체력 **50% 이상 = 1페이즈 / 50% 미만 = 2페이즈**, 최대 2페이즈.

### 6-3. 거리별 콤보 (x = 보스와 플레이어 간 거리)

| 거리 | 1페이즈 | 2페이즈 |
|---|---|---|
| 근거리 (x < 5) | 밟기 → (0.2초) → 기관총 3연발 | 밟기 → (0.1초) → 밟기 |
| 중거리 (5 ≤ x < 30) | 기관총 3연발 → (0.2초) → 기관총 연사 | 기관총 연사 → (0.1초) → 드론 소환* |
| 원거리 (x ≥ 30) | 곡사포 → (0.2초) → 돌진 | 곡사포 → (0.2초) → 돌진 |

\* 드론이 이미 1마리 이상 활성 상태면 기관총 연사로 대체

### 6-4. 예외 처리 — 동일 패턴 반복 방지
- 같은 패턴이 2회 연속 선택되면, 3번째 실행 시점에 해당 페이즈 후보군에서 **직전 패턴을 제외한 랜덤 패턴**으로 강제 교체한다.
  - 1페이즈 후보군: 밟기, 기관총 3연발, 기관총 연사, 곡사포, 돌진
  - 2페이즈 후보군: 위 5종 + 대포, 드론 소환

### 6-5. Resting (휴식)
- 콤보 종료 직후 진입. 1페이즈 2초 → 2페이즈 1초로 줄어 페이즈가 진행될수록 더 공격적으로 동작한다.

## 7. 패턴별 상세 사양

| 패턴 | 설명 | 공격 속도 | 데미지 | 시전 동작 시간 | 타입 | 범위 | 시작 위치 | 판정 박스 | 전조 연출 |
|---|---|---|---|---|---|---|---|---|---|
| **하단 공격 (밟기)** | 팔을 들어 전방 좌표에 내리찍음 | 1 | 3 | 1 | 범위 | 2 | 왼팔 | 보스 전방 x좌표, 2 범위 | 팔을 들어올림 |
| **기관총 3연발** | 오른팔 머신건에서 0.2초 간격으로 플레이어 위치를 향해 총알 발사 | 20 | 1 (개당) | 0.5 | 단일 | 1 | 오른팔 | 총알 오브젝트 | 오른손 머신건 장전 |
| **기관총 연사** | 오른팔 머신건에서 0.05초 간격으로 플레이어 위치를 향해 총알 발사 | 500 | 1 (개당) | 0.5 | 단일 | 1 | 오른팔 | 총알 오브젝트 | 오른손 머신건 장전 |
| **곡사포** | 등 뒤 곡사포로 플랫폼 및 플레이어 위치를 향해 발사 | 1 | 10 | 약 6~7초 ※ | 범위 | 3 | 등 뒤 | 대포 오브젝트 & 충격파 | 등 뒤 곡사포 장전 |
| **돌진** | 부스터로 플레이어 방향으로 빠르게 돌진 | 1 | 5 | 0.8 | 범위 | 10 | 온몸 | 돌진 경로상의 몸체 범위 | 등 뒤 부스터 점화, 불꽃 |
| **드론 소환** | 머리 뚜껑을 열어 드론 사출 | 0 | 0 | 1 | - | - | - | - | 머리 뚜껑이 열림 |

※ 곡사포 시전 시간 = 6발 발사(0.3초 간격) + 경고 1초 + 순차 낙하(0.5초 × n) + 마무리 1초

### 7-1. 곡사포 탄환 종류 (발사마다 가중치 랜덤)

| 탄종 | 동작 |
|---|---|
| 일반 | 바닥에 닿으면 터짐 |
| 공중폭발 (AirBurst) | 바닥에 닿기 전 공중에서 터지며 추가 탄환이 360도로 흩어짐 |
| 바운스 (BounceBlast) | 바닥에 닿아 터진 뒤 바닥에서 튀어오르는 탄환을 흩뿌림 |

## 9. 드론 시스템

- 보스 패턴에서만 등장하는 적.

### 지렁이 드론

**지휘자 드론 (머리)**
- 몸체 드론의 이동 방향을 결정하고 공격을 담당한다.
- ∞(8자) 경로로 이동한다.
- 플레이어 좌표를 받아 **3초마다 에너지탄 1발** 발사.
- 에너지탄은 매우 느리게 이동하며 시간이 지날수록 점점 커진다.

**몸체 드론 (몸통 × 8)**
- 서로 일정 거리를 두고 순서대로 지휘자 드론을 따라간다.
- 중간 드론이 파괴되면 그 자리는 **공백으로 남는다** (예: 5번 파괴 → 1, 2, 3, 4, _, 6, 7, 8).
- 지휘자 드론이 먼저 파괴되면 몸체 드론이 흩어지고, 플레이어 주변 일정 범위에서 랜덤 이동하며 총알 1발 발사 후 다시 이동한다.
  - 발사 주기: 1~3초 사이 랜덤

## 10. 페이즈 전환 및 사망 연출

### 10-1. 페이즈 전환 (HP 50% 최초 하회 시 1회만, 중복 방지 플래그)
1. 실행 중인 BT 트리를 2페이즈용으로 교체하고 신·구 트리 모두 리셋
2. 진행 중인 공격 패턴 코루틴 강제 중단, 애니메이터 트리거 전부 리셋
3. 부스터 이펙트 비활성화
4. 피격 무적/점멸 상태 즉시 해제
5. 씬에 남은 모든 발사체(총알·포탄·경고 마커)를 추적 리스트 기반으로 일괄 회수 (보스 이동 경로가 막히는 문제 방지)
6. 카메라에 부착된 화면 전환 이펙트 재생
7. Idle 상태로 재진입해 2페이즈 루프 시작

### 10-2. 사망 처리
1. 진행 중인 공격 패턴, 씬 내 모든 발사체, 활성 드론 전부 정리
2. 사망 애니메이션 재생, 배틀 BGM 정지
3. 2초 대기 후 사망 이펙트 생성, 보스 오브젝트 비활성화

## 11. 오브젝트 풀링 및 최적화

모든 발사체/드론은 오브젝트 풀로 사전 생성 후 재사용한다.

| 풀 종류 | 기본 크기 | 용도 |
|---|---|---|
| 총알 풀 | 50 | 기관총, 대포, 성장형 드론 총알 공용 |
| 대포탄 풀 | 50 | 곡사포 포탄 (`HowitzerCannonball`) |
| 경고 마커 풀 | 50 | 곡사포 착탄 예고, 드론 지상폭격 예고 공용 |
| 공중 폭발 파편 풀 | 50 | 곡사포 AirBurst 탄종 전용 |
| 바운스 파편 풀 | 50 | 곡사포 BounceBlast 탄종 전용 |
| 드론 풀 | 동시 활성 제한(1) + 2 | 드론 소환 패턴 전용 |

- 페이즈 전환·사망 시 씬에 남은 발사체를 일괄 회수해 방치된 오브젝트가 보스 이동을 막지 않게 한다.

## 13. 원문 점검 메모 (정리하면서 발견한 불일치)

- **밟기 / 하단 공격:** 콤보 표에서는 "밟기", 패턴 상세 표에서는 "하단 공격"으로 표기됨 → 같은 패턴으로 보고 정리함. 명칭 통일 필요.
- **대포:** 2페이즈 랜덤 후보군에 "대포"가 있지만 패턴 상세 표에는 없음 (총알 풀 용도에도 "대포" 언급).
- **성장형 드론:** 총알 풀 용도에 등장하지만 드론 시스템에는 지렁이 드론만 정의됨.
- **1페이즈 콤보 거리 조건:** 원문은 원거리를 `X < 30`, 중거리를 `5 > x < 30`으로 적어 조건이 겹침 → 이 문서에서는 근거리 x<5 / 중거리 5≤x<30 / 원거리 x≥30으로 해석함.
- **보스룸 연출 vs 보스시스템:** 공간 규격의 회전 레이저·RGB 판넬·거울·레이저 벽·아재 패턴이 보스시스템의 패턴/상태 정의에는 반영되지 않음.
