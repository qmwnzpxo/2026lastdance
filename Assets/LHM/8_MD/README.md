# docs/spec/ — 기획서 md 사본

> 원본은 기획서 docx(Google Docs)다. AI는 docx 대신 이 폴더의 md를 읽는다.
> **현민이 원본을 고치면 해당 md도 같이 고친다** (PROMPTS.md 12번으로 Claude에게 변환을 맡겨도 된다).
> AI는 이 폴더를 임의로 수정하지 않는다. 불일치를 발견하면 HANDOFF "기획서와 다르게 한 점" / "질문"에 적는다.
> 각 파일 맨 위에 `원본 버전: 1002.4v (YYYY-MM-DD)` 처럼 기획서 버전을 적는다.

| 파일 | 기획서 챕터 | 상태 |
|---|---|---|
| `boss.md` | 보스룸 공간 규격, 보스시스템, 보스 UI | ✅ **v2 확정** (2026-11-25, 스프라이트 기준 재설계 + 결정 17장. v1 원본 정리본은 `boss_system.md`) |
| `player.md` | 플레이어 시스템 (기본 사양, 이동, 전투, 칩, 중력 전환, 상태 우선순위, 선입력, 라이프 코인, 스탯 분배) | ⬜ |
| `skills.md` | 스킬 및 모드 메커니즘 (일섬, 프로 모션, 낙섬+QTE, 연섬) | ⬜ |
| `enemy.md` | 적 시스템 (타입, 인지·경보, 공격 슬롯, BT) | ⬜ |
| `supply.md` | 보급품 시스템 (상자, 드랍 표, 예외 규칙) | ⬜ |
| `level.md` | 레벨 디자인 (씬 구조, 웨이브 타임라인, 기믹, 챕터 1 플로우) | ⬜ |
| `cinematic.md` | 시네마틱 시스템, 대화·알림 시스템 | ⬜ |
| `ui.md` | UI/UX (HUD, QTE UI, 메뉴) | ⬜ |
| `story.md` | 세계관·시나리오·캐릭터 (구현 참고용, 우선순위 낮음) | ⬜ |

## 변환 규칙

- 기획서 문장을 바꾸지 않는다. 표·목록 형태만 정리한다.
- 수치는 표로 모은다 (SO 필드와 1:1로 대조하기 위해).
- 기획서 안에서 서로 맞지 않는 곳은 파일 끝 "원문 점검 메모"에 적는다. 임의로 하나를 고르지 않는다.
- 이미지는 넣지 않고 `[참고 이미지: 설명]` 으로 표시한다.
